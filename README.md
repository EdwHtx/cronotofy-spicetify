# Cronotofy — By EdwHtx

**Apple Liquid Glass UI, AI cover-based dynamic theme, animated personal album wall, and real-time listening analytics for Spotify Desktop.**

100% local and automatic: **no account, no login, and no external server required.** Everything adapts dynamically to your own Spotify library, top tracks/artists, playback cover art, and Spotify language (`en`, `es`, `pt`, `fr`, `de`, `it`).

---

## Features / Características

- **Apple Liquid Glass Theme:** Translucent smoked-crystal glass panels across the entire Spotify Desktop client (`GlobalNav`, sidebars, search dropdown, cards, and Now Playing bar) with smooth GPU-composited Dynamic Island navigation on scroll.
- **AI Dynamic Cover Palette (OKLab K-Means++):** Automatically extracts the dominant accent, secondary contrast, and ambient glass tint from your currently playing track's album art (or optionally via your own Gemini API key set locally in Console with `window.__CRONOTOFY_MOD__.setGeminiApiKey(...)`).
- **Animated Personal Album Wall:** Builds a living tilted cover-art marquee wall behind Spotify using exclusively your own top tracks, top artists, discographies, recent plays, and saved library.
- **Real-Time Listening Telemetry:** Tracks exact second-by-second session time and daily listening time in the bottom Now Playing bar alongside full rankings (`Overview`, `Artists`, `Tracks`, `Albums`, `Live Activity`) stored strictly in local browser storage.
- **Zero Login & Private:** Works out-of-the-box for any Spotify user without credentials or external syncing.

## Install (1-Click via Spicetify Marketplace)

1. Install [Spicetify](https://spicetify.app/) and **Spicetify Marketplace**.
2. Open **Marketplace** inside Spotify Desktop -> **Extensions**.
3. Search for **Cronotofy** and click **Install**.
4. Click the **Cronotofy** button next to the search bar (or the telemetry pills in the Now Playing bar) to toggle the analytics view, and press `Esc` or navigate anywhere in Spotify to return.

## Instalación (1 clic en Spicetify Marketplace)

1. Instala [Spicetify](https://spicetify.app/) y **Spicetify Marketplace**.
2. Abre **Marketplace** dentro de Spotify Desktop -> **Extensions**.
3. Busca **Cronotofy** y pulsa **Instalar**.
4. Pulsa el icono de **Cronotofy** a la derecha de la barra de búsqueda (o las píldoras de sesión/hoy en la barra inferior) para abrir tu panel en tiempo real. Sin inicios de sesión ni servidores externos: todo funciona de forma local con tu propia cuenta de Spotify.
